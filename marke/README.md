# Kestrel-Logo „Ring“

Der Wertungsring läuft oben rechts in einen Hakenschnabel aus, der Punkt ist das Auge. Ring und Turmfalke in einem Zeichen: die Skala und der genaue Blick.

Auf der Website kommt das Logo aus `src/components/Falke.astro` und nimmt dort die Textfarbe an.

## Regeln

- **Farbe:** nur einfarbig. Auf hellem Grund `#1d1d1f`, auf dunklem `#f5f5f7` oder Weiß. Keine Verläufe, keine Schatten, keine Medienfarben.
- **Schutzraum:** rundum mindestens der Durchmesser des Auges mal drei frei lassen.
- **Mindestgröße:** Master ab 48 px, darunter die Kleinfassung, nie kleiner als 16 px.
- **Mit Schriftzug:** „Kestrel“ in der Systemschrift (SF Pro, sonst Inter), Halbfett, Laufweite −2 %. Das Logo steht darüber oder links daneben, Abstand etwa eine Ringbreite.
- **Nicht:** drehen, spiegeln, verzerren, Auge entfernen, den Ring schließen, Konturen statt Flächen verwenden.
